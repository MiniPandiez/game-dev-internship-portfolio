# Game Development Internship Portfolio

A polished, single-page portfolio website for a game development internship candidate focused on gameplay programming, engine work, and systems scripting.

## Overview
This project presents a candidate with experience in:
- C++ gameplay programming
- C#, Lua, Python, and Unreal Blueprints
- Linear algebra and spatial reasoning
- Memory layout, bitfields, and low-level systems understanding
- Unreal Engine, Unity, and custom engine workflows
- Playable prototypes, game jams, and mechanics-focused projects

## Project goals
- Showcase technical gameplay programming strengths
- Emphasize systems, logic, and level flow over art fidelity
- Present a strong internship-ready portfolio profile
- Provide a nice visual design suitable for GitHub Pages or a personal portfolio site

## Files
- `index.html` — portfolio landing page
- `styles.css` — styling and layout
- `script.js` — small interactivity

## Local preview
Open `index.html` directly in a browser, or use a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization
Update the text in `index.html` with your real:
- name
- contact links
- project names
- personal summary
- portfolio links
